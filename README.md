# TimeNote for Obsidian

专为**周期日记（Daily Notes）**设计的时间轴与全周期日历视图插件。

---

## 🎯 核心特性

1. **直接以日记为唯一数据源**：
   - 不改变笔记习惯，无需将任务拆成独立 Markdown 文件；
   - 自动识别日记行内的 `14:00`、`14:00:31` 或 `14:00-15:30` 时间范围，并精准排布在时间网格上；
   - 支持并发重叠智能避让（多事件同时间段自适应分列排版）。
2. **全天待办分列垂直对齐**：
   - 无具体时间的行或任务，自动归入该日期的**「全天栏」**；
   - **严格按具体各天分列展示**，各归各天，不会混在一起；
   - 顶部日期栏、全天栏与下方时间轴列完全垂直对齐。
3. **列表主子项智能收纳**：
   - 严格只记录**主列表项**，缩进的子列表（带空格或Tab的子待办/要点）自动附属于父项；
   - 卡片上带有子项徽章（如 `▾3`），点击即可在弹窗中查阅所有子项内容，并支持一键定位原笔记行。
4. **双轨翻页导航**：
   - `⏮ 上周期` / `下周期 ⏭`：随当前视图按对应周期大跨度切换（1天 / 3天 / 1周 / 1月 / 1季度 / 1年）；
   - `◀ -1天` / `+1天 ▶`：精确按单日平滑推移；
   - `今天`：一键回归当前日期。
5. **双向无缝联动**：
   - 在日历界面上直接点击复选框，**实时回写并切换日记原文件中的 `[ ]` ↔ `[x]`**；
   - 点击条目卡片，**直接打开原日记并精确定位高亮对应行**；
   - 点击日历空白时间槽或「+ 记一条」，快速向当日日记插入新记录。

## 📅 七大视图模式

| 视图 | 标识 | 说明 |
| :--- | :--- | :--- |
| **日视图** | `Day` | 聚焦单日，全宽大卡片排布，直观呈现每小时记录与任务执行情况。 |
| **3天视图** | `3-Day` | 连续 3 天时间网格，适合短期排程与跨日任务对比规划。 |
| **周视图** | `Week` | 周一至周日 7 天纵览，上方各天全天待办独立分列，红线实时指示当前时刻。 |
| **月视图** | `Month` | 经典月历网格，带每日记录数量徽标，点击任意日期即可进入日视图。 |
| **季度视图** | `Quarter` | 当季 3 个月全景看板，展示季度累计条目、待办达成率、灵感统计与 3 月迷你日历。 |
| **年度视图** | `Year` | 全年 12 个月时间足迹全景，采用 GitHub 风格 5 级活跃度热力色块与全年统计。 |
| **时间线** | `Timeline` | 单日流水账瀑布流，带时间圆点轴线，支持子项层级预览与快速跳回原日记。 |

## 🚀 快速上手

1. **安装**：将 `manifest.json`、`main.js`、`styles.css` 放入 `<vault>/.obsidian/plugins/timenote/`，重启 Obsidian 并在「社区插件」中启用 **TimeNote**。
2. 在 Obsidian 左侧功能区点击时钟日历图标 `calendar-clock`，或在命令面板输入：
   `TimeNote: 打开时间笔记日历视图`
3. 在插件设置中可配置：
   - 周期笔记根目录（默认 `SpiralNotes`，自动支持 `SpiralNotes/YYYY/Daily/MM/YYYY-MM-DD.md` 结构）；
   - 是否聚合展示 `Blinko` 微闪念；
   - 默认视图模式、时间轴起止时间（默认 06:00 - 24:00）、一周起始日等。

## 🛠 本地开发

源码是 `main.ts`，`main.js` 为 esbuild 生成产物（仍入库，便于零构建安装）。**请勿直接编辑 `main.js`**。

```bash
npm install        # 首次拉取 devDependencies
npm run dev        # watch 模式，改动 main.ts 自动重建 main.js
npm run build      # tsc 类型检查 + 生产构建
npm run typecheck  # 仅类型检查
npm run check      # 类型检查 + PCMP 合规校验
```

构建链：TypeScript 7 + esbuild 0.28（CJS / browser，`obsidian` 保持 external，产物不压缩便于审阅）。改完代码先 `npm run build`，确保 `main.js` 与 `main.ts` 同步再提交。
